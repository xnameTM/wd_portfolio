# wd_portfolio

Next.js + Three.js starter with a rotating cube scene.

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the app.

## Three.js Starter

- Scene component: src/components/ThreeScene.tsx
- Page layout: src/app/page.tsx

## Build

```bash
npm run build
```
